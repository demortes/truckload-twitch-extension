Truckload Bridge

This is the telemetry source for Truckload, a Twitch extension that shows your current American Truck Simulator / Euro Truck Simulator 2 job and truck stats to your viewers.

Truckload is a native app, so there is nothing to use in the browser. Start the Truckload Bridge from the Start menu or your desktop shortcut (or run Truckload.Bridge.exe) while the game is running, and it will read telemetry from this page's /api/rest endpoints and send it to your channel.

Setup guide and source code: github.com/demortes/truckload-twitch-extension
