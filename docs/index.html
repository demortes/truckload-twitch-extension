Your delivery job, live on stream.

Truckload is a Twitch Extension for American Truck Simulator and Euro Truck Simulator 2 streamers. Viewers see your current job, route, and truck stats update in real time — no manual overlay setup required.

Download the Bridge View on GitHub

How it works

A small companion app reads your game's live telemetry and relays it through Truckload's backend to every viewer's Twitch Extension, over Twitch's own real-time PubSub — no polling, no delay.

1

ATS / ETS2

Your game exposes live telemetry via the SCS Telemetry SDK.

2

Truckload Bridge

A small app on your PC reads it and sends a normalized snapshot.

3

Backend

Validates, stores, and broadcasts it over Twitch PubSub.

4

Viewers

See it update live in the panel, overlay, or mobile view.

Get started as a streamer

Full walkthrough and troubleshooting live in docs/streamer-setup.md. The short version:

  1. Install the extension — activate the Panel and/or Video Overlay component from your Creator Dashboard.
  2. Generate your ingest key — open the extension's Config page and click "Generate API Key."
  3. Download and run the Bridge — grab Truckload.Bridge.exe from the latest release and run the command shown on the Config page: 
    Truckload.Bridge.exe --ingest-url https://<backend-domain>/api/ingest --key <your-key> --save
  4. Verify — start a job in ATS/ETS2; the Config page's Status section should show "Receiving data" within seconds.
